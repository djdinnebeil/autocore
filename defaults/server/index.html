Auto Core local files

server_ac.exe shares a folder with your web browser on this computer only (http://127.0.0.1:8585/ by default).

To add files you can browse:

  • Put files in this folder (the default document root is dist/server).
  • Add a directory junction or symlink to another folder (mklink /J or mklink /D).
  • Or set [server] document_root in config/server.ini to an absolute path. Keep a machine-specific path out of git.

This folder is local runtime data. Change the port in config/server.ini if 8585 is already in use. See docs/server.md in the Auto Core repository.
